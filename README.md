## Overview

Savings Circle Net digitizes traditional Rotating Savings and Credit Associations (ROSCAs). It empowers communities to manage collective savings pools securely and transparently using modern web technologies.

## Key Features

- **Group Management**: Easy tools for creating and managing savings circles.\n- **Automated Payouts**: Scheduled and secure fund distribution.\n- **Trust Scoring**: Reputation systems for circle members.\n- **Multi-Currency**: Support for diverse fiat and crypto assets.

## Getting Started

### Prerequisites

- Node.js v18+
- npm v9+

### Installation

```bash
git clone https://github.com/harobedjosh-alt/savings-circle-net.git
cd savings-circle-net
npm install
```

## Community Governance & Circles

### Circle Governance Models

#### Democratic Circles
- **One Person, One Vote:** Equal voting rights for all members
- **Proposal System:** Members can submit and vote on circle rules
- **Majority Decisions:** Simple majority for most decisions
- **Rotation Policies:** Community votes on payout rotation rules

#### Merit-Based Circles
- **Trust Scoring:** Higher influence for members with proven reliability
- **Performance Metrics:** Voting weight based on contribution history
- **Expert Panels:** Specialized committees for technical decisions
- **Graduated Authority:** Increased responsibilities for trusted members

#### Hybrid Governance
- **Core Team + Community:** Mix of appointed and elected representatives
- **Delegated Voting:** Members can delegate votes to trusted representatives
- **Emergency Powers:** Limited executive authority for urgent decisions
- **Regular Elections:** Democratic oversight of leadership roles

### Community Features

#### Circle Discovery
- **Browse Active Circles:** Filter by size, contribution amount, and region
- **Circle Ratings:** Community feedback and success metrics
- **Join Requests:** Application process for selective circles
- **Trial Periods:** Probationary membership for new participants

#### Member Management
- **Profile System:** Detailed member profiles with trust scores
- **Dispute Resolution:** Community arbitration for conflicts
- **Member Removal:** Democratic process for handling issues
- **Legacy Planning:** Rules for handling member departure or inactivity

#### Educational Resources
- **ROSCA Guides:** Educational content about rotating savings
- **Success Stories:** Case studies from successful circles
- **Financial Literacy:** Basic financial education modules
- **Community Forums:** Discussion spaces for circle participants

### Governance Principles
- **Transparency:** All decisions and finances are publicly auditable
- **Fairness:** Equal opportunity for all qualified participants
- **Security:** Multi-signature controls and smart contract enforcement
- **Sustainability:** Long-term viability and community benefit focus
